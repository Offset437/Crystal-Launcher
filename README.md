# Crystal Launcher

A Windows launcher for FINAL FANTASY XI. Launch your accounts, update the game and manage your settings in one place.

## Download

**[Download the latest release](https://github.com/Offset437/Crystal-Launcher/releases/latest)**

Choose the **Setup.exe** for installation with Desktop and Start menu shortcuts, or the **portable ZIP** to run without installing. Game files are not included.

## Features

- Launch one account or several together with Vanilla, Windower or Ashita.
- Choose profiles and optional automatic character login for each account.
- PlayOnline friends, online status and messages.
- Check, update and repair FFXI and PlayOnline, with resumable downloads and backups.
- Xbox, PlayStation and ROG Xbox Ally controller setup, plus controller navigation through the launcher.
- Graphics settings and optional dgVoodoo and ReShade setup.
- Official news, maintenance notices, BG Wiki and FFXIAH searches.
- Privacy mode to hide account details on screen.

## Setup

Requires Windows and a retail FFXI account. The US Windows client is the currently tested configuration.

1. Open Crystal. It looks for installed FFXI, PlayOnline, Windower and Ashita folders. Use **Browse** if it misses yours.
2. For a fresh installation, get the official Square Enix installer from **Downloads** and install PlayOnline and FFXI. Run **Check files**, then **Update** if needed.
3. Add your accounts under **Accounts**, or use **Import accounts** for saved PlayOnline or Forest accounts. Fill in any missing login details.
4. Choose your launch method and profile, select your accounts, then click **Play selected**.

Saved accounts and settings are kept through launcher updates and reinstalls for the same Windows user. Close games and sign out of PlayOnline sessions before updating or repairing game files.
